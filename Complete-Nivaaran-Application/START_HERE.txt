NIVAARAN – START HERE (Windows)

1. Install Node.js 18+ and MySQL Server.
2. Open database/schema.sql in MySQL Workbench and execute it.
3. Copy .env.example to .env and set your MySQL password.
4. Open terminal in this folder:
      npm install
      npm run seed
      npm run dev
5. Visit http://localhost:4000
