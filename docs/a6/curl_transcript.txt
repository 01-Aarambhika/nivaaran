4. STATE CONFLICT (Status 409 Conflict with Problem Details)
--------------------------------------------------------------------------------
$ # First escalation succeeds
$ curl -i -X POST http://localhost:8082/complaints/cmp_1001/escalate \
  -H "Authorization: Bearer test-token-ritik" \
  -H "Content-Type: application/json" \
  -d '{"initiatorId":"20251651078","reason":"SLA turnaround expired"}'

HTTP/1.1 200 OK
Content-Type: application/json; charset=utf-8
Content-Length: 422

{
  "id": "cmp_1001",
  "status": "submitted",
  "isEscalated": true
}

$ # Duplicate escalation triggers State Conflict
$ curl -i -X POST http://localhost:8082/complaints/cmp_1001/escalate \
  -H "Authorization: Bearer test-token-ritik" \
  -H "Content-Type: application/json" \
  -d '{"initiatorId":"20251651078","reason":"Attempting second escalation"}'

HTTP/1.1 409 Conflict

Connection: keep-alive
